# Battle of the Crowns (B.O.C.)

A small medieval real-time strategy game built for phones. Gather food, wood, gold and stone, advance through four ages, wall up your town and hold off a computer rival.

**Play:** https://man31209-alt.github.io/Battle-of-the-Crowns/

On your phone, open the link, then use your browser's **Add to Home Screen**. After the first visit it works offline, and the game saves itself every 30 seconds.

All code and art are original (the graphics are drawn in code). No ads, no timers, no purchases.

## Files
- `index.html`: layout and styling
- `game.js`: the whole game (map, units, buildings, AI, controls, saving)
- `sw.js` + `manifest.webmanifest`: offline support and home-screen install
