# Battle of the Crowns (B.O.C.)

A medieval real-time strategy game built for phones, with game systems inspired by the open-source game 0 A.D.

**Play:** https://man31209-alt.github.io/Battle-of-the-Crowns/

Open the link on your phone and use **Add to Home Screen**. After the first visit it works offline, and the game saves itself every 30 seconds.

## What's in it
- **19 civilizations**, each with its own bonus, unique unit and hero: English, French, Holy Roman Empire, Castilians, Byzantines, Saracens, Vikings, Celts, Japanese, Chinese and Mongols, in four architecture styles.
- **17 map types** (Mainland, Rivers, Great Lake, Coastline, Highlands, Desert Oasis, Nordic Fjords, Inland Sea, Black Forest, Steppe, Gold Rush, Fortress, Mountain Pass, Red Canyon, Marshlands, Alpine Valley, Islands) plus Random, in three sizes, with up to 3 computer rivals. Mountains are impassable, so passes and canyons become choke points.
- **Three phases** (Village, Town, City) unlocked by building up your town.
- **Territory**: town centers and castles claim land, and most buildings must go inside it.
- **Citizen soldiers** who fight, gather and build. **Capturing** buildings with melee troops.
- **Fields** that never run out, hunting (deer, sheep, boar), and **fishing boats**, docks and war galleys.
- **Markets** with barter and trade carts, **monasteries** with healing monks, **ranks** for veteran soldiers, hero auras.
- Unit **stances**, **attack-move**, **garrisoning**, **batch training**, the town bell, walls, gates and towers.
- Game options: ceasefire timer, Wonder victory, starting resources and population limit.

All code and art are original (everything is drawn in code). No ads, no timers, no purchases.

## Files
- `index.html`: layout, setup screen and styling
- `game.js`: the whole game (map generation, units, buildings, AI, controls, rendering, saving)
- `sw.js` + `manifest.webmanifest`: offline support and home-screen install
